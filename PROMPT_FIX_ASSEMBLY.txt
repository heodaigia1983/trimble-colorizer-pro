Mở file app.js trong thư mục trimble-colorizer-pro (cùng cấp index.html, manifest.json).

Yêu cầu: hàm fetchQuantities() đang gom nhóm "Tên cấu kiện" bằng cách lấy property đầu tiên khớp pattern rộng (assembly mark/position/name, mark, position, drawing no) — nên nếu model có cả "Drawing No." và "Assembly Position" trên cùng object, có thể nó chọn nhầm "Drawing No." trước. Cần ưu tiên tuyệt đối property tên đúng "Assembly Position" trước, các pattern khác chỉ là fallback khi không có "Assembly Position".

1) Tìm đoạn này (gần dòng 272-276):

var QTY_PATTERNS = {
  weight: /NetWeight|GrossWeight|^Weight$/i,
  length: /^Length$/i,
  assembly: /assembly.*(mark|position|name)|^mark$|^position$|drawing\s*no/i
};

Thay bằng:

var QTY_PATTERNS = {
  weight: /NetWeight|GrossWeight|^Weight$/i,
  length: /^Length$/i
};
var ASSEMBLY_TIERS = [
  /^assembly\s*position$/i,
  /assembly.*(mark|position|name)/i,
  /^mark$/i,
  /^position$/i,
  /drawing\s*no/i
];
